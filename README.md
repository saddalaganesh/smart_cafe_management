☕ Smart Cafe Management System

A full-stack food ordering and cafe management web application built using Flask, Python, SQLite, HTML, CSS, and Jinja2.

🚀 Overview

Smart Cafe is a role-based web application that allows customers to browse menu items, add products to a cart, place orders, and track order status. Administrators can manage menu items, monitor orders, update order statuses, and view dashboard analytics.

✨ Features

Customer Features

- User Registration & Login
- Browse Menu Items
- Add Items to Cart
- Remove Items from Cart
- Place Orders
- View Order History
- Track Order Status

Admin Features

- Secure Admin Login
- Add New Menu Items
- Edit Existing Menu Items
- Delete Menu Items
- Manage Customer Orders
- Update Order Status
- Dashboard Analytics
